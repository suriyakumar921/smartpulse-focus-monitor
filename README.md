# SmartPulse Focus & Wellness Monitor

A Node.js wellness and focus pacing monitor built with @smartspectra/node-sdk that reads camera-based breathing and cardiac metrics and provides gentle session cues.

## Prerequisites
- Node.js >= 20 (Node 24 LTS recommended)
- Supported platform: macOS Apple Silicon (darwin-arm64), Linux x64/ARM64 (linux-x64, linux-arm64 with glibc >= 2.35), or Windows x64 (win32-x64)
- Camera connected and a Presage SmartSpectra API key (physiology.presagetech.com)
